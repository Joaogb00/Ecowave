ECOWAVE

Bem-vindo ao EcoWave, uma plataforma desenvolvida com o objetivo de utilizar a tecnologia como ferramenta de incentivo à reciclagem e à sustentabilidade.

O projeto busca aproximar usuários de pontos de coleta de materiais recicláveis, facilitando a localização desses estabelecimentos e criando um sistema que incentiva o descarte correto de resíduos.

Além de facilitar o processo de reciclagem, o EcoWave utiliza recursos como reconhecimento de materiais, sistema de recompensas, localização de pontos de coleta e gerenciamento de reciclagens para tornar a experiência mais simples, acessível e interativa.


SOBRE O PROJETO

O descarte incorreto de materiais recicláveis ainda representa um problema ambiental significativo. Muitas pessoas possuem interesse em reciclar, mas não sabem onde realizar o descarte ou quais estabelecimentos próximos recebem determinados tipos de materiais.

O EcoWave foi desenvolvido pensando justamente nesse problema.

A plataforma conecta usuários e proprietários de pontos de coleta, permitindo que materiais recicláveis sejam identificados, registrados e encaminhados para locais adequados.

O sistema também utiliza um mecanismo de recompensas através de moedas virtuais, incentivando o usuário a continuar reciclando e permitindo que suas ações dentro da plataforma gerem benefícios.

Dessa forma, o EcoWave busca unir tecnologia, sustentabilidade e conscientização ambiental em uma única aplicação.


OBJETIVO

O principal objetivo do EcoWave é facilitar e incentivar a reciclagem através de uma plataforma digital simples e acessível.

A plataforma busca permitir que o usuário:

Encontre pontos de coleta de materiais recicláveis;

Identifique quais materiais são aceitos em cada ponto;

Registre suas reciclagens;

Acompanhe seu histórico de reciclagem;

Receba moedas virtuais como recompensa;

Utilize suas moedas dentro da plataforma;

Identifique materiais através de inteligência artificial;

Encontre rotas até os pontos de coleta;

Tenha acesso a informações relacionadas à reciclagem e sustentabilidade.


DIFERENCIAL

O diferencial do EcoWave está na integração de diferentes tecnologias para tornar o processo de reciclagem mais simples e interessante para o usuário.

A plataforma não funciona apenas como um sistema para encontrar pontos de coleta. Ela também permite registrar reciclagens, acompanhar materiais descartados, receber recompensas e utilizar inteligência artificial para auxiliar na identificação de objetos recicláveis.

Outro diferencial está na existência de diferentes níveis de acesso dentro da plataforma, permitindo que usuários comuns, proprietários de pontos de coleta e administradores tenham funcionalidades específicas de acordo com suas responsabilidades.

SISTEMA DE USUÁRIOS

O EcoWave possui diferentes tipos de usuários dentro da plataforma.

O usuário comum pode utilizar as principais funcionalidades relacionadas à reciclagem, encontrar pontos de coleta, registrar atividades e acompanhar suas recompensas.

Caso tenha interesse em cadastrar e administrar um ponto de coleta, o usuário pode realizar uma solicitação para se tornar proprietário.

Essa solicitação é analisada pela administração da plataforma e pode ser aceita ou recusada. Em caso de recusa, o sistema permite informar uma justificativa ao usuário.


PAINEL DO PROPRIETÁRIO

Os proprietários possuem acesso a recursos específicos para gerenciamento dos seus pontos de coleta.

Dentro do painel, é possível cadastrar informações relacionadas ao estabelecimento, endereço, CEP, materiais aceitos e horários de funcionamento.

Essas informações são utilizadas para permitir que outros usuários encontrem pontos adequados para realizar o descarte dos seus materiais recicláveis.


PAINEL ADMINISTRATIVO

O EcoWave também possui uma área destinada à administração da plataforma.

O painel administrativo permite acompanhar usuários cadastrados e analisar solicitações realizadas por usuários que desejam se tornar proprietários de pontos de coleta.

O administrador pode aceitar ou recusar essas solicitações, mantendo maior controle sobre os estabelecimentos cadastrados na plataforma.


SISTEMA DE RECICLAGEM

O sistema permite registrar as reciclagens realizadas pelos usuários.

Durante o processo, podem ser registradas informações como o material reciclado, sua quantidade em quilogramas e o ponto de coleta responsável pelo recebimento.

Após a confirmação da reciclagem, o usuário recebe moedas virtuais de acordo com a atividade realizada.

As reciclagens também ficam disponíveis no histórico do usuário, permitindo acompanhar suas contribuições ao longo do tempo.


SISTEMA DE RECOMPENSAS

O EcoWave utiliza um sistema de moedas virtuais como forma de incentivar a participação dos usuários.

Ao realizar ações relacionadas à reciclagem, o usuário pode acumular moedas dentro da plataforma.

Essas moedas podem posteriormente ser utilizadas na loja disponível no sistema, transformando a reciclagem em uma experiência mais interativa e recompensadora.


RECONHECIMENTO DE MATERIAIS

Uma das funcionalidades do EcoWave é o reconhecimento de materiais utilizando inteligência artificial.

Através dessa tecnologia, o sistema pode analisar objetos e auxiliar na identificação do tipo de material apresentado pelo usuário.

O recurso utiliza TensorFlow para realizar o reconhecimento e adapta os resultados para facilitar a compreensão dentro da plataforma.

Essa funcionalidade busca auxiliar principalmente usuários que possuem dúvidas sobre a identificação ou classificação de determinados materiais.


LOCALIZAÇÃO E ROTAS

O EcoWave facilita a localização dos pontos de coleta cadastrados na plataforma.

Os usuários podem pesquisar estabelecimentos e utilizar filtros para encontrar pontos que recebem determinados tipos de materiais.

A plataforma também possui integração com serviços externos de localização e transporte, permitindo abrir rotas com o destino do ponto de coleta previamente definido.

Dessa forma, o usuário consegue encontrar um local adequado e obter uma rota para chegar até ele de maneira mais prática.


SEGURANÇA E CONFIRMAÇÃO

Algumas operações da plataforma utilizam mecanismos adicionais de confirmação.

O sistema pode enviar um código de quatro dígitos por e-mail para validar determinadas ações.

O código possui um período limitado para utilização, adicionando uma etapa de confirmação ao processo realizado pelo usuário.

EXECUTANDO O PROJETO

Para executar o projeto localmente, primeiro clone o repositório:

git clone URL_DO_REPOSITORIO

Entre no diretório do projeto:

cd ecowave

Instale as dependências necessárias:

npm install

Configure as variáveis de ambiente necessárias para o funcionamento do banco de dados e dos serviços utilizados pela aplicação.

Execute as configurações necessárias do Prisma e do banco de dados.

Em seguida, execute o ambiente de desenvolvimento:

npm run dev

Dependendo da organização do repositório, o front-end e o back-end podem precisar ser iniciados separadamente.

VISÃO DO PROJETO

O EcoWave parte do princípio de que a tecnologia pode ser utilizada não apenas para resolver problemas digitais, mas também para incentivar mudanças positivas no mundo real.

A proposta do projeto é facilitar o acesso à reciclagem e diminuir algumas das barreiras existentes entre uma pessoa que deseja realizar o descarte correto e os locais preparados para receber esses materiais.

Ao combinar pontos de coleta, inteligência artificial, localização, recompensas e gerenciamento de reciclagens, o EcoWave busca transformar uma ação ambiental importante em um processo mais simples, acessível e integrado à tecnologia.
